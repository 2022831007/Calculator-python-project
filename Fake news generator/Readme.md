# 🔥 Fake News Headline Generator

## 📌 Project Overview

The **Fake News Headline Generator** is a simple Python project that generates funny and random fake news headlines. It uses Python's built-in `random` module to combine random subjects, actions, and places or things to create unique and entertaining headlines.

This project is designed for beginners to practice Python lists, random selection, f-strings, loops, and user input.

## ✨ Features

* Generates random and funny news headlines.
* Combines subjects, actions, and places or things randomly.
* Allows users to generate multiple headlines.
* Lets users exit the program whenever they want.
* Displays headlines with emojis for a fun experience.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Module:** `random` (built-in Python module)

## 🚀 How to Run the Project

### Prerequisites

Make sure Python 3 is installed on your computer.

### Steps

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python3 main.py
```

4. The program will generate a random fake news headline.
5. Enter `yes` to generate another headline or `no` to exit.

## 💻 Example Output

```text
🔥 Breaking News: Habib Wahid dances with at zinda park

Do you want another headline? (yes/no): yes

🔥 Breaking News: A Group of Monkeys orders inside parliament

Do you want another headline? (yes/no): no
```

*Note: The generated headlines are random, so the output may vary each time.*

## 📚 Python Concepts Practiced

* **Lists:** Store subjects, actions, and places or things.
* **`random.choice()`:** Selects a random item from a list.
* **While Loop:** Repeats the headline-generation process.
* **F-strings:** Combine strings and variables to create headlines.
* **User Input:** Allows users to decide whether to continue.
* **`strip()`:** Removes extra whitespace from user input.
* **Conditional Statements:** Checks whether the user wants to exit.
